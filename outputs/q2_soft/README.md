# 问题二：增强型方案 A（普通物资软约束对照版）

本目录专门保存用于对照的方案 A。医疗物资的期望送达时间和首批保障货箱的首批截止时间为硬约束；普通物资的期望送达时间不作为可行性判据，而按“应急优先系数 × 正迟到时间”计入配送及时性目标。

运行命令：

```bash
python scripts/run_q2_soft.py
```

代码与硬时间窗版本完全隔离：软约束模型使用 `q2_transport_soft.py`、`q2_soft_solver.py`、`q2_soft.py` 和 `q2_soft.toml`，结果只写入本目录。因此后续调整硬约束版本不会覆盖该对照版本。

正式运行后，`tables/` 保存主方案、基线、Pareto前沿和搜索记录，`pareto/` 保存各代表方案的架次、逐箱交付和独立复核。
